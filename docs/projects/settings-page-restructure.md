# 项目任务书：设置页重构 + 学期管理

> 面向维护此功能的 AI agent / 开发者。术语沿用根 `CONTEXT.md`。
> **本任务书是改动二。改动一是 `docs/projects/submission-checklist.md`，两者分两次上线**——一次全上 diff 太大，出问题不好定位（现行习惯是改完 `python deploy.py` 立刻线上验证）。

## 1. 背景

`tutoring-system/src/pages/SettingsPage.tsx` 已 600 行 / 9 个 `<section>`，单列长滚动。改动一还要再加两节（学期管理、提交清单模板）→ 11 节，找东西已经要一路扫标题。

## 2. 决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 左侧分类目录 + 右侧**只渲染当前分类**（真 tab，非锚点滚动） | 11 节的正解。锚点滚动页面照样长；accordion 全折叠后找东西还是扫标题。 |
| D2 | 「学期管理」**吃掉**现有「归档管理」 | 归档管理本来就是一张 round 列表。再单开一个 round 编辑界面 = 两处都列 round，必然分叉。 |
| D3 | 新建 round 的入口**不动**（仍在加学生时 new round） | 频率极低（一届一次），现有入口够用。 |
| D4 | 当前分类记 `localStorage` | 跟 `dashboard-view-mode` 的既有习惯一致。 |

## 3. 分组

```
外观    界面主题
教学    默认学期 / 学期管理 / 提交清单模板 / 知识库上下文来源
集成    iCloud 日历同步 / Zoom 账号配置 / 腾讯文档 API
AI      AI 模型配置
数据    数据备份与恢复
```

（归档管理不再单列，并入 教学 → 学期管理。）

## 4. 学期管理界面

一张表，每行一届：

```
学期    普通 ddl            延期 ddl            学生数  归档
26春    08.14 五 17:00      08.21 五 17:00      12      [ ]   ▸
25秋    03.13 五 17:00      03.20 五 17:00      8       [x]   ▸
```

- 两个 ddl 用 datetime 选择器（精确到小时），可留空 → 该届学生 ddl 显示「待定」
- 展开 `▸`：学生列表（只读）+ 下载完整 JSON —— **原样搬运现有归档管理的展开内容**
- 归档开关沿用现有逻辑（归档届及其学生全局排除；归档时若命中 `default_round` 自动清空）
- 写入走 `PUT /api/rounds/{name}/deadlines`（改动一里已加）

## 5. 实施注意

- 纯重构 + 一个新分节，**不改任何现有 section 的内部逻辑**。搬 JSX，不重写。
- 改动一已经把 `PUT /api/rounds/{name}/deadlines` 和「提交清单模板」那节做完了；本次只负责把它们放进新框架。若改动二先做，则本次先建空框架，模板那节留到改动一填。
